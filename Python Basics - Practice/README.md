# Python Basics - Practice

Hands-on exercises to build confidence in core Python before touching the
"Advanced" roadmap folders (generators, decorators, NumPy, etc). Every file
here is a set of small, standalone tasks — no solutions are included on
purpose, so you can judge your own output before asking for a review.

## Order
Work through the files in this order — each one leans lightly on the skills
from the ones before it:

1. `01_variables_and_operators.py`
2. `02_data_types_and_conversion.py`
3. `03_strings.py`
4. `04_conditionals.py`
5. `05_loops.py`
6. `06_lists_and_tuples.py`
7. `07_dictionaries_and_sets.py`
8. `08_functions.py`
9. `09_exception_handling.py`
10. `10_file_handling.py`
11. `11_mini_project_contact_book.py` — capstone that combines everything above

## How to work through a file
1. Open the file, read the topic docstring at the top.
2. Solve each `TODO` in order, directly below the comment (add code, don't
   delete the comment — it's your record of what the task was).
3. Run the file (`python "01_variables_and_operators.py"` or the VS Code Run
   button) after every TODO or two — don't write five in a row untested.
4. If your printed output looks right to you, move to the next TODO. If a
   `TODO` mentions an error or edge case, that's intentional — read the
   traceback, don't avoid triggering it.

## Self-check before asking for a review
For each file, ask yourself:
- Does the code run without crashing (except where an error is the point)?
- Does the printed output match what the task actually asked for?
- Could you explain *why* your code works, out loud, without looking at it?

If yes to all three, you're ready for that file to be reviewed.

## Getting evaluated
When you've finished a file (or a few), say so and paste/point to the file —
I'll review it, tell you what's solid, what's fragile, and what a cleaner
version would look like, without just handing you the "correct" answer
first. Treat each file as gradeable independently; you don't need to finish
all 11 before asking for feedback on the first one.
